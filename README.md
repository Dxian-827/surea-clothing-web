# SUREA — British Heritage Clothing for Dogs

A refined lifestyle brand for dogs, people and the places you share.

## Overview
This is the static demo showcase for the SUREA pet clothing brand, featuring:
- Home showcase with luxury British editorial visual language
- Full product catalog & category filters (Clothing, Walk Set, Travel, Home)
- Product detail view with size selector & accordion details
- Responsive shopping cart & mock checkout experience
- Brand story, editorial journal, size guides, shipping & returns

## Tech Stack
- Pure HTML5 / CSS3 / Vanilla JavaScript
- Zero external build dependencies
- Responsive layout with fluid typography and bespoke styling
